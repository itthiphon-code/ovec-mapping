# รายงาน PDF และ Word

## วิธีใช้งาน

- ผู้ใช้ทั่วไป: ค้นใบรับรอง เลือกระดับและ UoC ที่สอบผ่าน กรองรายวิชา แล้วเลือก **สรุปรายวิชาและแหล่งอ้างอิง** หรือ **รายวิชาพร้อมตารางหลักฐานรายข้อ** จากนั้นกด **ดาวน์โหลด PDF** หรือ **ดาวน์โหลด Word**
- รายงานใช้เฉพาะรายวิชาที่กรองไว้ ณ เวลากดดาวน์โหลด ระบุจำนวนวิชา ตัวกรอง ขอบเขตหน่วย และรอบข้อมูล ไม่ต้องเปิดตารางหลักฐานทีละวิชาก่อนส่งออก
- เจ้าหน้าที่: เปิด `/reports?mapping=…` เลือกตารางเทียบ สรุป บัญชีหลักฐาน หรือความเห็นผู้เชี่ยวชาญ แล้วดาวน์โหลดตามแท็บที่เลือก ตารางเทียบใช้ A4 แนวนอน
- Word เป็น `.docx` จริง แก้ไขได้ พร้อมข้อความ “สำเนาแก้ไขได้ โปรดตรวจฉบับรับรอง” ส่วน PDF เป็นไฟล์ดาวน์โหลดโดยตรง ปุ่มพิมพ์เดิมยังใช้ได้

## ขอบเขตและความถูกต้อง

รายงานผู้ใช้ทั่วไปไม่แสดงคะแนนหรือเปอร์เซ็นต์ มีมาตรฐาน ระดับ UoC ที่เลือก รหัสวิชา สาขา ทฤษฎี–ปฏิบัติ–หน่วยกิต หลักฐาน PC ตำแหน่งเอกสาร URL ช่องว่าง และ SHA-256 ตามข้อมูลที่มี ผลจับคู่อัตโนมัติไม่ใช่การอนุมัติเทียบโอน และรายงานไม่สร้างลายเซ็นหรือผู้รับรองสมมติ

รายงานเจ้าหน้าที่ใช้สถานะ เลขฉบับ และความเห็นที่ได้รับจาก API ตามสิทธิ์เดิม แสดงให้เห็นเมื่อความเห็นเป็นคนละ revision/hash ไม่มีการเปลี่ยนสถานะงานหรืออัปโหลดรายงานอัตโนมัติ การแก้ Word ไม่เปลี่ยนข้อมูลในระบบหรือสร้างฉบับรับรองใหม่

## การพัฒนาและตรวจสอบ

- `lib/report-data.ts`: สร้างข้อมูลรายงานจากผลเทียบจริง โดยไม่ส่งต่อคะแนนไปยังแบบรายงานผู้ใช้ทั่วไป
- `lib/report-export.ts`: สร้าง PDF/OOXML ภายในเครื่องผู้ใช้ โหลดตัวสร้างไฟล์เมื่อกดดาวน์โหลดเท่านั้น ไม่ส่งข้อมูลไปบริการแปลงไฟล์ภายนอก
- `components/report-download.tsx`: ปุ่ม สถานะระหว่างจัดทำ และการลองใหม่เมื่อเกิดข้อผิดพลาด
- `public/fonts/`: Sarabun Regular/Bold พร้อมใบอนุญาต OFL จาก [Google Fonts](https://github.com/google/fonts/tree/main/ofl/sarabun) ฝังฟอนต์ใน PDF และฝัง Regular ใน DOCX โปรแกรม Word ที่ไม่ใช้ฟอนต์ฝังอาจจัดหน้าแตกต่างจาก PDF
- `npm run check`: ตรวจชนิดข้อมูล lint การทดสอบ และ build
- `node --import tsx scripts/verify-report-exports.ts`: สร้างไฟล์ตรวจรูปแบบใน `tmp/report-qa/` จากชุดข้อมูลมาตรฐาน 151 และ fixture เจ้าหน้าที่ที่ระบุว่าเป็นข้อมูลทดสอบ ไม่เขียนฐานข้อมูลจริง

การตรวจรูปแบบต้องเปิดภาพที่เรนเดอร์จากทั้ง PDF และ DOCX รวมถึงหน้าตารางต่อเนื่อง ภาษาไทย และเลขหน้า หากตัวเรนเดอร์ไม่มีฟอนต์ไทย ให้ชี้ Fontconfig ไปยัง `public/fonts/` ก่อนตรวจ

อ้างอิงตัวสร้างเอกสาร: [pdfmake custom fonts](https://pdfmake.github.io/docs/0.1/fonts/custom-fonts-client-side/), [pdfmake tables](https://pdfmake.github.io/docs/0.1/document-definition-object/tables/), [docx Packer](https://docx.js.org/api/classes/Packer.html)
