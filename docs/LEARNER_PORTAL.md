# หน้าผู้ใช้งานทั่วไปของ OVEC Mapping

## การเลือกรายวิชาเพื่อออกรายงาน

หลังเลือก UoC หน้ารายละเอียดใบรับรองเรียงรายวิชาตามคะแนนความสอดคล้องจากมากไปน้อย โดยไม่แสดงคะแนน วิชาที่คำนวณไม่ได้อยู่ท้ายรายการ หากคะแนนเท่ากันใช้น้ำหนักการอ้างอิงเอกสารเดิม การเลือกหลักฐาน PC ภายใน matcher ยังคงให้อ้างอิงเอกสารก่อน

ผู้ใช้ติ๊กวิชาที่จะเสนอพิจารณา หรือเลือกทุกวิชาที่แสดงได้ แยกตัวตนวิชาด้วยรหัสสาขาและวิชา รายการที่เลือกคงอยู่ขณะค้นหรือกรอง และแสดงจำนวนที่อยู่นอกตัวกรอง การพิมพ์และ PDF/Word ใช้เฉพาะวิชาที่เลือกทั้งหมด เรียงลำดับเดียวกับหน้าจอ ปุ่มปิดใช้งานเมื่อยังไม่เลือกวิชา การเปลี่ยน UoC หรือระดับใบรับรองล้างรายการเลือก การเลือกเป็นสถานะชั่วคราวในหน้านี้และยังไม่ใช่การอนุมัติเทียบโอน

## หน้าค้นหาและบริการผู้ใช้

หน้าผู้ใช้ทั่วไปไม่แสดงเปอร์เซ็นต์หรือคะแนนการจับคู่ ทั้งการค้นจากวิชา รายวิชาที่เสนอ ตารางหลักฐานรายข้อ และผลพิมพ์จากหน้าเหล่านี้ ยังคงแสดงหลักฐาน ขอบเขตและสิ่งที่ต้องตรวจ การคำนวณและจัดอันดับภายใน รวมถึงการแสดงคะแนนในพื้นที่เจ้าหน้าที่ทำงานตามเดิม

หน้า `/` ค้นได้สองทาง: ชื่ออาชีพ/สาขาตามใบรับรอง หรือรหัส/ชื่อรายวิชา มีตัวอย่างคำค้น ตัวกรอง แบ่งหน้า และแนวทางเมื่อไม่พบผล หน้ารายละเอียดใบรับรองยังให้ผู้ใช้เลือกระดับและ UoC ที่สอบผ่านจริงก่อนแสดงรายวิชา

`/prepare` เป็นเช็กลิสต์เอกสารที่พิมพ์ได้ แยกสิ่งที่ระบบใช้ยื่น คำแนะนำประกอบ และเอกสารเมื่อเจ้าหน้าที่ร้องขอ การติ๊กเป็นสถานะชั่วคราวในหน้า ไม่ใช่การอัปโหลดหรือยืนยันความครบถ้วน `/help` มี FAQ การอ่านผลค้นหา ความหมายของ UoC ข้อจำกัด แนวทางติดต่อฝ่ายทะเบียน และแหล่งข้อมูลต้นทาง

`/documents` และ `/applications` แสดงข้อมูลของผู้ใช้เอง รวมถึงเมื่อผู้ใช้นั้นเป็น admin คลังเอกสารตั้งประเภทเริ่มต้นเป็นคุณวุฒิวิชาชีพและรับ PDF ไม่เกิน 15 MB แบบคำร้องแนบใบรับรองหลัก 1 ไฟล์และไฟล์ประกอบสูงสุด 10 ไฟล์ เปิดคลังเอกสารในแท็บใหม่แล้วโหลดรายการใหม่ได้โดยไม่ทิ้งแบบคำร้อง

พื้นที่เจ้าหน้าที่เดิมอยู่ `/dashboard`, `/staff-documents`, `/staff-applications` และเส้นทางรับรองเดิม หน้าผู้ใช้ทั่วไปใช้เมนูแนวนอน เมนูมือถือ และภาพเอกสาร 3D ด้วย CSS ไม่มีการเปลี่ยนผู้ได้รับอนุญาตเข้าเว็บไซต์

## ความน่าเชื่อถือ

ใช้ immutable snapshots เดิม การค้นจากวิชาแสดงสูงสุด 3 มาตรฐานที่คัดไว้ต่อวิชา อาจมีใบรับรองอื่นนอกชุดผล คะแนนเป็นความคล้ายของข้อความ ไม่ใช่หน่วยกิตหรือความน่าจะเป็นที่จะเทียบผ่าน

เช็กลิสต์เป็นคำแนะนำเตรียมคำร้อง ไม่ใช่ข้อกำหนดเดียวกันทุกสถานศึกษา ไม่มีการกำหนดอายุใบรับรอง ระยะเวลาพิจารณา หรือค่าธรรมเนียมแทนสถานศึกษา ไม่ขอบัตรประชาชนเพื่อค้นหา และไม่อ้างว่าตรวจเลขใบรับรองกับ TPQI อัตโนมัติ

แหล่งอ้างอิงในหน้าช่วยเหลือ: [บริการ TPQI-Net](https://www.tpqi.go.th/e-service/tpqi-net/) สำหรับข้อมูลมาตรฐานและตรวจสอบสถานะการรับรอง และ [ค้นรายวิชาอาชีวศึกษา](https://dles.vec.go.th/subject/) รายการเอกสารแนะนำของระบบไม่ได้อ้างว่าเป็นรายการบังคับจากเว็บไซต์เหล่านี้

## การจัดเก็บและสิทธิ์

รายการเอกสารและคำร้องรับ `mine=1` เพื่อจำกัดเจ้าของ แม้ผู้ดูเป็น admin การละพารามิเตอร์คงสิทธิ์เดิม ผู้เรียนขยายสิทธิ์ด้วย `mine=0` ไม่ได้ หน้าส่วนตัวไม่แสดงปุ่มปรับสถานะแบบเจ้าหน้าที่

`additionalDocumentIds` เก็บใน application payload JSON เดิม ไม่ต้อง migration ตรวจ UUID, สูงสุด 10 ไฟล์, ไม่ซ้ำกับไฟล์หลักหรือกันเอง และทุกไฟล์ต้องเป็นของผู้ยื่น เอกสารที่ผูกคำร้องเปิดได้ตามสิทธิ์เจ้าของ/admin/registrar/approver ผู้ใช้อื่นยังได้รับ 404 คำร้องเดิมที่ไม่มี field นี้ยังใช้ได้และไม่ถูกแก้ไข

## ตรวจรับ

`node scripts/test-learner-portal.mjs` ผ่าน 38 local HTTP checks: ค้น/กรอง/แบ่งหน้า, ตามวิชาไปยังมาตรฐาน, รายการส่วนตัว, ป้องกันแนบไฟล์คนอื่น/ซ้ำ/เกินจำนวน, สิทธิ์อ่านเอกสารก่อนและหลังผูกคำร้อง, รักษาสถานะยังไม่รับรอง, รองรับคำร้องเดิม และอ่านทุกหน้าหลักได้ สคริปต์ลบแถวทดสอบหลังจบ ไม่สร้างคำร้องจริงบนเว็บที่เผยแพร่
